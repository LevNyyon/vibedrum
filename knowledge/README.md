# vibedrum knowledge

One pack per genre, the same documents in each: README (index), vocabulary (the request playbook), grooves, fills, dynamics-and-feel, song-structure.

| pack | genre |
|---|---|
| djent/ | modern metal and djent |

Choosing the pack:

1. He names a genre or a band: use that pack.
2. Otherwise run `show --summary` and compare tempo, keeper, feel and kick/bar with the "it is this genre when" lines at the top of each pack README.
3. Still unclear: ask one question.

A request can aim at a genre the file is not in ("make this chorus more pop punk"). Read the target pack for the sound, and keep the file's own pack for what an edit must not break.
